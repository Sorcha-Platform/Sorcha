# Documentation Archive

Historical documentation preserved for reference. The bulk of these files were archived on 2026-03-01 during a documentation consolidation; later obsolete design/plan docs have been added since. **These files are not maintained and may not reflect the current system** — for current documentation see the [docs README](../README.md), [`docs/architecture.md`](../architecture.md), and [`docs/reference/development-status.md`](../reference/development-status.md).

## Categories

- **implementation-plans/** — pre-implementation design documents and sprint plans.
- **plans/** — dated design/plan artefacts (verifiable-credentials, shared-library NuGet, code-quality passes, the never-built documentation API-portal design/plan, etc.).
- **sessions/** — session summaries, troubleshooting notes, and fix reports.
- **completion-reports/** — phase completion and status reports.
- **cli-history/** — CLI sprint summaries and integration task lists.
- **learnings/** — retrospective notes (e.g. validator-service refactoring).

## Loose files (root of this folder)

- `FINAL-TEST-SUMMARY.md`, `HD-WALLET-IMPLEMENTATION-SUMMARY.md`, `HTTPS-SETUP-COMPLETE.md` — one-off summaries from early work.
- `DOCKER-MACVLAN-NETWORKING.md.deprecated` — superseded networking notes (kept for provenance; the `.deprecated` suffix marks it as such).

> All content here is point-in-time. Nothing outside this folder should link to it as a source of current truth; the only inbound references should be historical citations (e.g. an ADR citing the report that motivated it).
