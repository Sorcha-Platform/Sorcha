Brief → System · what I changed and why

A refinement, not a rebrand

The palette and the "S" mark are kept. I reconciled everything to the values inside the icon — the real source of truth — and retired the lighter drift the landing page had wandered into. Five decisions worth your sign-off before the detail:

Retired the lighter #667eea / #764ba2 drift

The icon's true ground is #090A14→#0F1020 with primary #6366F1 and a deep #4F46E5 in the S's shadow. The landing's lighter pair is gone; the system is anchored to the mark.

The green #48bb78 accent is demoted to success only

It read as a second brand colour and fought the indigo. It now appears solely as the harmonised success state — never as a brand or CTA accent.

#6366F1 is a glow colour, #4F46E5 is the action colour

White on #6366F1 is only 4.47:1 — it fails AA for normal text. So filled buttons and links use #4F46E5 (white = 6.3:1), and #6366F1 is reserved for large display, icons, borders and bloom.

Verification accent = a luminous violet step (my recommendation)

You asked me to weigh a complementary hue. I recommend staying in-family: #A5B4FC for "verified / proof". Restraint signals seriousness; a fourth hue reads consumer-SaaS. A "hallmark gold" alternate is wired in — toggle it below to judge.

Deliverable 4 · Imagery & motion

Grid, particle, bloom — extended

One visual language carried through the whole site: a faint 56px grid, slow-drifting glow-squares, and a soft violet bloom. Line-based, geometric, monochrome with a single accent. No photography, no 3D, no clichés.

Section divider — a grid baseline fading to a single bloom particle

How it works · four line icons

01
Issue

A credential is minted against an agreed schema.

02
Sign

Post-quantum signatures (ML-DSA / SLH-DSA) seal it.

03
Distribute

Each party receives the credential and its evidence.

04
Verify

Anyone re-checks the math — no operator in the loop.

Motion — calm by mandate

The hero <canvas> drifts particles at ~0.12px/frame, twinkling between #6366F1 and #818CF8 at 18–48% opacity. It snaps to the 56px grid, blurs softly, and never loops attention-grabbing motion.

Off-screen + reduced-motion

An IntersectionObserver pauses the loop when the hero scrolls away. prefers-reduced-motion renders a single static frame — no animation, full contrast, content always visible.

Deliverable 5 · Implementation

Plain CSS variables & a MudBlazor palette

No build step, no framework. The marketing page consumes the CSS custom properties; the Blazor app maps the same hexes into a MudTheme. One source of truth, two surfaces.
