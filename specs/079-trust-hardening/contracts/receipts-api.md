# API Contract: Transaction Receipts

**Service**: Register Service
**Base Path**: `/api/registers/{registerId}`

## Endpoints

### GET /transactions/{txId}/receipt

Retrieve the transaction receipt for a sealed transaction.

**Authorization**: `CanReadTransactions` policy

**Path Parameters**:
| Parameter | Type | Description |
|-----------|------|-------------|
| registerId | string | Register ID |
| txId | string | Transaction ID |

**Response 200 OK**:
```json
{
  "receiptId": "a1b2c3d4...",
  "transactionId": "e5f6a7b8...",
  "registerId": "reg-001",
  "docketNumber": 42,
  "merkleRoot": "f0e1d2c3...",
  "inclusionProof": {
    "transactionHash": "e5f6a7b8...",
    "docketNumber": 42,
    "merkleRoot": "f0e1d2c3...",
    "proofPath": [
      { "hash": "1a2b3c4d...", "position": "left" },
      { "hash": "5e6f7a8b...", "position": "right" }
    ],
    "leafIndex": 3,
    "treeSize": 10
  },
  "signatures": [
    {
      "validatorAddress": "sorcha1abc...",
      "signatureValue": "base64...",
      "algorithm": "ED25519",
      "signedAt": "2026-03-31T12:00:00Z"
    }
  ],
  "sealedAt": "2026-03-31T12:00:00Z",
  "version": 1
}
```

**Response 404 Not Found**: Transaction not found or not yet sealed.
```json
{
  "error": "receipt_not_found",
  "message": "No receipt exists for transaction {txId}. The transaction may not yet be sealed."
}
```

### GET /dockets/{docketNumber}/receipts

Retrieve all receipts for transactions sealed in a specific docket.

**Authorization**: `CanReadTransactions` policy

**Path Parameters**:
| Parameter | Type | Description |
|-----------|------|-------------|
| registerId | string | Register ID |
| docketNumber | long | Docket height |

**Query Parameters**:
| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| page | int | 1 | Page number |
| pageSize | int | 20 | Items per page (max 100) |

**Response 200 OK**:
```json
{
  "items": [ /* array of TransactionReceipt */ ],
  "totalCount": 10,
  "page": 1,
  "pageSize": 20
}
```

### POST /receipts/verify

Verify a receipt's validity without register access (portable verification).

**Authorization**: None (public endpoint for offline-compatible verification)

**Request Body**:
```json
{
  "receipt": { /* TransactionReceipt object */ },
  "validatorPublicKey": "base64..."
}
```

**Response 200 OK**:
```json
{
  "isValid": true,
  "checks": {
    "signatureValid": true,
    "inclusionProofValid": true,
    "merkleRootConsistent": true
  }
}
```

**Response 200 OK (invalid)**:
```json
{
  "isValid": false,
  "checks": {
    "signatureValid": false,
    "inclusionProofValid": true,
    "merkleRootConsistent": true
  },
  "errors": ["Validator signature verification failed"]
}
```

## Internal Endpoints (Service-to-Service)

### POST /receipts/batch

Store a batch of receipts generated by the Validator during docket sealing.

**Authorization**: `CanWriteDockets` policy (service token)

**Request Body**:
```json
{
  "docketNumber": 42,
  "receipts": [ /* array of TransactionReceipt */ ]
}
```

**Response 201 Created**:
```json
{
  "stored": 10,
  "docketNumber": 42
}
```

## SignalR Events

### Event: TransactionReceipt

**Hub**: RegisterHub (`/hubs/register`)
**Group**: `register:{registerId}`
**Method**: `TransactionReceipt`

**Payload**:
```json
{
  "transactionId": "e5f6a7b8...",
  "registerId": "reg-001",
  "docketNumber": 42,
  "receiptId": "a1b2c3d4...",
  "sealedAt": "2026-03-31T12:00:00Z"
}
```

**Note**: Lightweight notification. Client should call `GET /transactions/{txId}/receipt` for full receipt data.
