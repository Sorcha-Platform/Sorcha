# Phase 1 Contracts: AI Discoverability & Machine-Readable Marketing

**Feature**: 117-ai-discoverability

This directory captures the over-the-wire shapes and the document templates the implementation must produce. Three categories:

1. **HTTP endpoints** — well-known URIs, request/response shape, headers.
2. **Schemas** — JSON Schema for the MCP manifest.
3. **Document templates** — `llms.txt` and `STANDARDS.md` shape, in `*-template.md` files alongside this README.

---

## 1. HTTP endpoints

### `GET /.well-known/openapi.json` (new)

**Auth**: anonymous
**Cache-Control**: `public, max-age=300`
**Content-Type**: `application/json`

**200 Response**: A valid OpenAPI 3.1 JSON document. Generated by `Microsoft.AspNetCore.OpenApi` and post-processed by `OpenApiInfoTransformer` to inject `info.x-mcp-server`, `info.x-standards`, and the canonical `info.version`. See `openapi-extensions.md` for the required extension shape.

### `GET /.well-known/openapi.yaml` (new)

**Auth**: anonymous
**Cache-Control**: `public, max-age=300`
**Content-Type**: `application/yaml`

**200 Response**: The same document as `openapi.json`, serialised as YAML via `YamlDotNet`. Identical content modulo serialisation.

### `GET /.well-known/mcp.json` (new)

**Auth**: anonymous
**Cache-Control**: `public, max-age=300`
**Content-Type**: `application/json`

**200 Response**: A JSON document validating against `mcp-manifest.schema.json`. See `mcp-manifest-example.json` for an example payload.

### `GET /api/mcp/tools` (new)

**Auth**: anonymous (read-only catalogue; describing tools, not executing them)
**Cache-Control**: `public, max-age=300`
**Content-Type**: `application/json`

**200 Response**:

```json
[
  {
    "name": "BlueprintCreate",
    "category": "designer",
    "description": "Creates a new Sorcha blueprint from a JSON or YAML document. Use when an agent has finalised a blueprint design and wants to register it for the first time; prefer `BlueprintUpdate` if the blueprint already exists at the given title.",
    "parameter_schema_url": "/api/mcp/tools/BlueprintCreate/schema"
  },
  ...
]
```

Total entries: 36 (13 admin + 13 designer + 10 participant).

### `GET /api/mcp/tools/{toolName}/schema` (new)

**Auth**: anonymous
**Cache-Control**: `public, max-age=300`
**Content-Type**: `application/json`

**200 Response**: JSON Schema for the named tool's parameters, derived from the tool's C# parameter type.

**404 Response**: Tool name not found.

### Existing endpoints — unchanged

`GET /openapi/v1.json`, `GET /openapi/aggregated.json`, the Scalar UI at `/openapi/`, `GET /api/health`, `GET /api/docs`, `GET /api/stats`, etc. all remain unchanged. The `/.well-known/*` paths are co-served aliases plus the new MCP discovery surface.
